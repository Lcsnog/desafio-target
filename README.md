Desafio Target.
Repositório com os exercícios desenvolvidos em C# para o processo seletivo da Target.

EXERCÍCIOS:
1.Comissão
- Exercício para calcular a comissão de acordo com os valores informados.

2.Juros de Dívida
- Programa que calcula os juros de uma dívida de acordo com a data de vencimento e os dias de atraso.

3.Movimentação de Estoque
- Programa para controle de estoque, permitindo realizar entradas e saídas de produtos e acompanhar o estoque após cada movimentação.

Tecnologias utilizadas:
- C#
- .NET
- Visual Studio
- Git
- GitHub
- JSON
